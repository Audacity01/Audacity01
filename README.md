### Featured: MouseBridge

**One mouse, keyboard and clipboard for your Windows PC and your Mac.** Push the pointer off the edge of one screen
and it carries on on the other computer, with the keyboard and clipboard following it. Screens are laid out at their
real physical size, so the pointer crosses exactly where the displays meet on your desk, even between a 34" ultrawide
and a 13" laptop.

- C# / **.NET 10** with **Avalonia**: one codebase for Windows and macOS
- Paired with a security key, encrypted, local network only: no account, no cloud
- **Download:** [Audacity01/mousebridge-releases](https://github.com/Audacity01/mousebridge-releases)
